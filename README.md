**Đọc trước khi làm bất cứ gì:** [`PROGRESS.md`](./PROGRESS.md) (trạng thái hiện tại) → [`CLAUDE.md`](./CLAUDE.md) (luật làm việc, vai trò) → [`PROJECT_CONTEXT.md`](./PROJECT_CONTEXT.md) (kiến trúc/schema/API chi tiết). Người dùng cuối xem [`USER_GUIDE.md`](./USER_GUIDE.md).
