Đây là dự án [Next.js](https://nextjs.org), khởi tạo bằng [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Bắt đầu

Chạy server phát triển:

```bash
npm run dev
# hoặc
yarn dev
# hoặc
pnpm dev
# hoặc
bun dev
```

Mở trình duyệt vào [http://localhost:3000](http://localhost:3000) để xem kết quả.

Bạn có thể bắt đầu sửa trang bằng cách chỉnh file `app/page.tsx`. Trang sẽ tự cập nhật khi bạn lưu file.

Dự án này dùng [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) để tự động tối ưu và tải font [Geist](https://vercel.com/font), 1 font chữ mới của Vercel.
